# وِرَاق | Waraq

تطبيق ملاحظات وقاعدة معرفة عربي، خفيف ومحلي أولًا، مبني باستخدام Electron وJavaScript وCSS. يستخدم ملفات Markdown عادية داخل مجلد تختاره أنت، لذلك يمكن فتح مجلد Obsidian موجود والعمل على ملفاته مباشرة.

## التشغيل على Windows

1. ثبّت **Node.js LTS** من الموقع الرسمي: https://nodejs.org/
2. فك ضغط المشروع إلى مسار عادي، مثل `C:\\Apps\\Waraq`.
3. افتح PowerShell داخل مجلد المشروع.
4. نفّذ:

   ```powershell
   npm install
   npm start
   ```

في التشغيل الأول ينشئ وِرَاق مجلد `Waraq Vault` داخل مجلد Documents إذا لم يكن هناك مجلد سابق محفوظ في الإعدادات. يمكنك تغيير مجلد الملاحظات من زر **تغيير** أو من الإعدادات واختيار مجلد Obsidian مباشرة.

## بناء ملف تثبيت

بعد تثبيت الحزم:

```powershell
npm run dist:win
```

ستجد ملفات التوزيع في `release/`. على Linux استخدم `npm run dist:linux`.

> قد يحتاج بناء نسخة Windows من Linux إلى إعدادات cross-build إضافية. أسهل مسار لبناء ملف التثبيت هو تشغيل الأمر على Windows نفسه.

## الوظائف الموجودة

- واجهة عربية RTL بستايل داكن/فاتح وتخطيط متعدد اللوحات.
- محرر Markdown، ومعاينة قراءة، ووضع تحرير ومعاينة جنبًا إلى جنب.
- إنشاء الملاحظات والمجلدات وإعادة التسمية وسلة مهملات داخلية.
- حفظ تلقائي قابل للتعطيل، مع حفظ يدوي باستخدام `Ctrl+S`.
- روابط داخلية بصيغة `[[اسم الملاحظة]]` وروابط عكسية.
- خريطة مرئية للملاحظات المرتبطة.
- بحث في عناوين الملاحظات ومحتوياتها، وانتقال سريع ولوحة أوامر.
- وسوم `#وسم`، مفضلة، قائمة عناوين الملاحظة (Outline)، وملاحظة يومية.
- إضافة صور ومستندات وملفات إلى `.attachments` داخل مجلد المعرفة.
- تصدير أي ملاحظة إلى Markdown أو نص، وفتح مجلد المعرفة في مدير الملفات.
- إعدادات حجم الخط والمظهر، وأيقونات SVG مضمنة محليًا.
- استيراد عملي لمجلد Obsidian بفتحه مباشرة؛ ملفات Markdown الموجودة تظل ملفات عادية.
- واجهة Electron مع `contextIsolation` و`nodeIntegration: false` وواجهة IPC محدودة في `preload.js`.

| `Ctrl+I` | نص مائل |
| `Ctrl+G` | خريطة المعرفة |
| `Esc` | إغلاق النافذة المنبثقة |

## ملاحظات التوافق والحدود

وِرَاق ليس نسخة مطابقة من Obsidian، ولا يستخدم شعاره أو أصوله الخاصة. وهو يوفّر وظائف محلية أساسية في مساحة معرفة عربية، لكنه لا يتضمن خدمة مزامنة سحابية خاصة أو متجر إضافات متوافقًا بالكامل مع إضافات Obsidian المدفوعة/المجتمعية. يمكن وضع مجلد المعرفة داخل مجلد متزامن عبر OneDrive أو Dropbox أو أي خدمة ملفات متوافقة. بعض تنسيقات Obsidian الخاصة، والـCanvas والإضافات، قد لا تظهر بنفس سلوك Obsidian.

المعاينة المدمجة تدعم العناوين والفقرات والقوائم والاقتباسات والكود والروابط الداخلية والخارجية والصور الأساسية. ليست محرك CommonMark/GFM كاملًا في هذا الإصدار.

## هيكل المشروع

- `main.js` — نافذة Electron وعمليات الملفات الآمنة عبر IPC.
- `preload.js` — واجهة محدودة بين الصفحة وعمليات النظام.
- `index.html` — هيكل الواجهة.
- `styles.css` — المظهر الداكن/الفاتح والتخطيط.
- `renderer.js` — إدارة الملاحظات والمحرر والبحث والروابط والخريطة.
- `assets/logo.svg` — الشعار الأصلي.
